# Метаданные для каталогов приложений

Структура, которую читают F-Droid и IzzyOnDroid. Никакого fastlane как
инструмента здесь нет и не нужно — каталоги просто договорились брать
описание из этих файлов, а не из выдачи Google Play.

```
metadata/android/<локаль>/
  title.txt               имя в каталоге
  short_description.txt   одна строка, не длиннее 80 символов
  full_description.txt    полное описание
  changelogs/<код>.txt    что изменилось; имя файла — versionCode из pubspec
  images/icon.png         512×512
  images/phoneScreenshots/1.png … 8.png
```

Скриншоты лежат только в `en-US`: интерфейс на них английский, и класть
те же кадры под русское описание значило бы выдавать их за русские.
Каталог подставит их из основной локали сам.

Следующий релиз: положить `changelogs/<новый versionCode>.txt`. Номер
берётся из `pubspec.yaml` — из числа после `+`.
